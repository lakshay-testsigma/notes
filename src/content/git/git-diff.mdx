<Analogy>
Spot-the-difference: two snapshots side by side, and Git circles only what moved.
</Analogy>

<TLDR>
- `git diff` compares **commits, branches, files, the working directory** — and more.
- Bare `git diff` = **staging area ↔ working directory**: changes NOT staged for the next commit.
- `git diff HEAD` = everything since the last commit. `--staged` / `--cached` = what's about to be committed.
- Output order: which files (**A** and **B**) → metadata you ignore → `@@` chunk header → `-` lines from A, `+` lines from B.
- `..` compares two named things: `branch1..branch2`, `commit1..commit2`.
</TLDR>

<Callout type="info">
Use it alongside `git status` and `git log` — together they give the full picture of a repo and how it changed.
</Callout>

## Which two snapshots?

Three places your code can live. Each flag picks a different pair.

    { icon: "🧭", label: "git diff HEAD", note: "Last commit ↔ working tree." },
    { icon: "📦", label: "--staged", note: "Last commit ↔ staging area." }

<Diagram caption="Three snapshots, three comparisons. The flag chooses the pair." chart={`
flowchart LR
  C["Last commit<br/>HEAD"] -->|"--staged"| S["Staging area"]
  S -->|"git diff"| W["Working directory"]
  C -.->|"git diff HEAD"| W

<CodeBlock lang="bash" title="the three core forms">{`git diff              # staging area vs working directory — unstaged changes only
git diff HEAD         # last commit vs working tree — everything since the commit
git diff --staged     # last commit vs staging area
git diff --cached     # identical to --staged, older spelling`}</CodeBlock>

<Callout type="tip">
`--staged` answers: *"show me what will be included in my commit if I run `git commit` right now."*
</Callout>

## Decoding `@@ -3,4 +3,5 @@`

The header between the two `@@` marks says which slice of each file you are looking at.

<Diagram caption="Same starting line, different length — A lost one line, B gained two." chart={`
flowchart LR
  H["@@ -3,4 +3,5 @@"] --> A["file a<br/>4 lines @3"]
  H --> B["file b<br/>5 lines @3"]
`} />

| Part | Reads as |
| --- | --- |
| `-3,4` | from **file A**, 4 lines extracted starting at line 3 |
| `+3,5` | from **file B**, 5 lines extracted starting at line 3 |
| `-` prefix | this line comes from file A |
| `+` prefix | this line comes from file B |
| no prefix | unchanged context line |

## Narrowing it down

Pass a filename to diff just that file.

<CodeBlock lang="bash" title="one file at a time">{`git diff HEAD rainbow.txt        # unstaged + staged changes, this file only
git diff --staged rainbow.txt    # staged changes, this file only`}</CodeBlock>

## In 30 seconds

<Diagram caption="Read any diff top to bottom in this order." chart={`
flowchart LR
  A["diff --git<br/>which files"] --> B["index<br/>ignore"] --> C["--- a<br/>+++ b"] --> D["@@ chunk @@"] --> E["- from A<br/>+ from B"]
`} />

| You want | Command |
| --- | --- |
| Unstaged work | `git diff` |
| Everything since last commit | `git diff HEAD` |
| What the next commit will contain | `git diff --staged` |
| One file only | `git diff HEAD [file]` |
| Two branches | `git diff branch1..branch2` |
| Two commits | `git diff commit1..commit2` |
