<Analogy>
Branches let you work in a sealed-off side quest. Merging brings the loot back
to the main story.
</Analogy>

<TLDR>
- `git merge` incorporates changes from one branch into another.
- Two rules: you merge **branches, not commits**, and always **into the current HEAD branch**.
- Nothing diverged → **fast-forward**: the pointer just slides forward.
- Both sides moved → **merge commit**: a new commit on the receiving branch, message prompted.
- Git can't decide → **merge conflict**: edit the markers yourself, then add and commit.
</TLDR>

## Not all merges are fast-forwards

A teammate lands work on master while you're on your branch — this happens all the time.

| Situation | Git does |
| --- | --- |
| Receiving branch never moved | **Fast-forward** — move the pointer, no new commit |
| Both branches moved | **Merge commit** — new commit on the receiving branch, message prompted |

## Heads up: merge conflicts

<Callout type="warning">
Depending on the changes, Git may not be able to merge automatically. You resolve
those conflicts by hand.
</Callout>

<CodeBlock lang="bash" title="Git warns you in the console">{`CONFLICT (content): Merge conflict in blah.txt
Automatic merge failed; fix conflicts and then commit the result.`}</CodeBlock>

It also rewrites the file to show you what it wants resolved — WHAT THE…

<CodeBlock lang="text" title="blah.txt">{`<<<<<<< HEAD
I have 2 cats
I also have chickens
=======
I used to have a dog :(
>>>>>>> bug-fix`}</CodeBlock>

| Between these markers | Content from |
| --- | --- |
| `<<<<<<< HEAD` … `=======` | your current **HEAD** — the branch you're merging into |
| `=======` … `>>>>>>> bug-fix` | the branch you're **merging from** |

## Resolving conflicts

<Steps
  caption="Four moves, for every conflicted file."
  items={[
    { icon: "📂", label: "Open files", note: "Open the file(s) Git listed as conflicted." },
    { icon: "✂️", label: "Pick content", note: "Decide per conflict: keep yours, keep theirs, or keep both." },
    { icon: "🧽", label: "Strip markers", note: "Delete the <<<<<<<, ======= and >>>>>>> markers." },
    { icon: "✅", label: "Add + commit", note: "Stage your changes and make the commit." }
  ]}
/>

<CodeBlock lang="bash" title="Finish the merge">{`# once every conflicted file is clean
git add .
git commit -m "Merge bugfix into master"`}</CodeBlock>

## Deleting a branch

<Steps
  caption="Merged branches are disposable — the pointer goes, the merged commits stay on master."
  items={[
    { icon: "🌿", label: "Bugfix done", note: "Its work is merged into master." },
    { icon: "🗑️", label: "Delete pointer", note: "git branch -d bugfix" },
    { icon: "🧹", label: "Clean history", note: "Only the master line is left." }
  ]}
/>

<CodeBlock lang="bash" title="Delete a branch">{`git branch -d bugfix   # remove the bugfix branch pointer`}</CodeBlock>

<Callout type="tip">
`-d` refuses to delete a branch whose work isn't merged yet; `-D` forces it.
</Callout>
