<TLDR>
- `git stash` shelves all uncommitted work, staged **and** unstaged, and reverts your working copy.
- The stash is **repo-wide, not per-branch** — stash on one branch, pop it on another.
</TLDR>

## Stash it

<CodeBlock lang="bash" title="Shelve everything uncommitted">{`git stash
git stash save   # deprecated spelling of git stash push (no pathspecs)`}</CodeBlock>

## Pop vs apply

| Command | Restores | Stash afterwards |
| --- | --- | --- |
| `git stash pop` | most recent stash | removed |
| `git stash apply` | most recent stash | still there |

<CodeBlock lang="bash" title="Restore">{`git stash pop
git stash apply
git stash pop --index`}</CodeBlock>

<Callout type="warning">
Pop and apply bring modified files back **unstaged** — only a brand-new file stays staged. Add `--index` to restore the exact staging state.
</Callout>

## Heads up — untracked files

<Callout type="warning">
Files you have **never** checked in to Git are not included in a stash. `-u` fixes that.
</Callout>

<CodeBlock lang="bash" title="Include untracked files">{`git stash -u`}</CodeBlock>

## Pick, drop, clear

<Steps
  caption="Three deep — watch the stack change with each command."
  items={[

    { icon: "🎯", label: "apply stash@{2}", note: "Applies that one, not the newest — stack still three deep." },
    { icon: "🗑️", label: "drop stash@{2}", note: "That stash is deleted — two left." },

<CodeBlock lang="bash" title="Managing the stack">{`git stash apply stash@{2}
git stash drop <stash-id>
git stash clear`}</CodeBlock>
