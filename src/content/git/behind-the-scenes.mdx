<TLDR>
- Git is a **key-value store**: give it content, get a **SHA-1** key back.
- Four object types: **commit**, **tree**, **blob**, **annotated tag**.
- A commit points at a **tree**, trees point at **blobs** and other trees.
- Branches and tags are just **files holding a hash** (a commit, or for annotated tags a tag object); HEAD is a file holding a branch name.
- Change one byte → new hash → new blob → new tree → new commit.
</TLDR>

## Read them yourself

<CodeBlock lang="bash" title="Peek inside">{`cat .git/HEAD                 # ref: refs/heads/master
cat .git/refs/heads/master    # 40 hex digits — the tip commit
ls  .git/refs/tags            # one file per tag
git config --local user.email "me@work.com"   # this repo only → .git/config`}</CodeBlock>

<Callout type="info">
You'll often see these called "encrypted" — they're zlib-**compressed**, not encrypted. Unreadable in a text editor, but not secret.
</Callout>

<Callout type="info">
Git uses **SHA-1** — always a 40-digit hexadecimal number. Those commit hashes
you've seen a million times *are* SHA-1 output — and it hashes files, directories
and commits alike. (Git is set to move off SHA-1 eventually.)
</Callout>

## Git is a key-value database

<Steps
  caption="The keys are SHA-1 checksums — nothing else identifies your data."

    { icon: "🔎", label: "Ask by key", note: "“Hello Git, what's stored under dd7e1c6f…?”" },
    { icon: "📤", label: "Get value", note: "Git hands back 'goodbye'. Only the key was needed." }
  ]}
/>

<CodeBlock lang="bash" title="Store and retrieve, for real">{`echo 'hello' | git hash-object --stdin -w
# ce013625030ba8dba906f756967f9e9ca394464a

git cat-file -p ce013625030ba8dba906f756967f9e9ca394464a
# hello`}</CodeBlock>

| Command / flag | Does |
| --- | --- |
| `git hash-object <file>` | Prints the key the file **would** get. Stores nothing |
| `--stdin` | Hash piped input instead of a file (`echo` just repeats text into the pipe) |
| `-w` | Actually **write** the object — then look in `.git/objects` |
| `git cat-file -p <hash>` | Pretty-print the object, formatted by its type |

## What each object holds

| Object | Stores | Doesn't store |
| --- | --- | --- |
| **blob** | The contents of a file | Filenames, or anything else |
| **tree** | Per entry: mode, type, SHA-1, filename | File contents |
| **commit** | tree, parent(s), author, committer, message | Files directly |
