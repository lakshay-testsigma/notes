<TLDR>
- **Version control** = software that tracks and manages changes to files over time.
- Git = the world's most popular one. Subversion, CVS, Mercurial do the same job differently.
- Every save is a **checkpoint**; you can branch off an old one and merge branches back.
- Built by **Linus Torvalds**, April 2005 — existing tools were slow, closed-source, paid.
- **Git ≠ GitHub.** Git is local software; GitHub just hosts Git repos online.
</TLDR>

## Where it came from

<Diagram caption="Torvalds wanted a VCS that was fast AND free — the rest were slow, closed-source, usually paid." chart={`
flowchart LR
  A["2005<br/>frustrated"] --> B["Apr 3<br/>writes Git"] --> C["+2 months<br/>first release"] --> D["2020<br/>90% use it daily"]

Linus Torvalds — creator of Linux — called it "the stupid content tracker".
The official source gives the name four meanings, by mood:

| Mood | "Git" = |
| ---- | ------- |
| Neutral | Random pronounceable 3 letters, unused by any UNIX command |
| Self-deprecating | "stupid, contemptible, despicable — simple" |
| It works | "global information tracker" |
| It breaks | "g#ddamn idiotic truckload of sh\*t" |

## Git ≠ GitHub

<Steps
  caption="Git works fully offline. GitHub is the optional place you push it to."
  items={[
    { icon: "💻", label: "Your machine", note: "Full history, local. No account, no internet." },
    { icon: "⬆️", label: "Push", note: "Upload that history to share it." },
    { icon: "☁️", label: "GitHub", note: "A service that hosts Git repos. Account required." },
    { icon: "👥", label: "Others clone", note: "Teammates get their own full copy and push back." }
  ]}
/>

| | **Git** | **GitHub** |
| --- | --- | --- |
| What | Version control software | Cloud host for Git repos |
| Runs | Your machine | Browser / cloud |
| Account | No | Yes |
| Internet | No | Yes |
| For | Tracking & combining changes | Sharing & collaborating |

<Callout type="tip">
You can use Git forever without touching GitHub. Not the other way round.
</Callout>
