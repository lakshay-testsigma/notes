<TLDR>
- `git clone <url>` works on any **public** repo — no account, no permission.
- Nothing goes up until `git push <remote> <branch>`.
</TLDR>

## Git vs GitHub

| | **Git** | **GitHub** |
| --- | --- | --- |
| What | Version control software | Cloud host for Git repos |
| Runs | Locally, on your machine | Online service |
| Account | Never needed | Required |
| Internet | Never needed | Required |
| Gives you | Commits, branches, merges | Collaboration features Git lacks |
| Alone? | Usable for life, GitHub untouched | Just where Git work gets shared |

## Not the only option, but the biggest

| Fact | Number |
| --- | --- |
| Rivals | GitLab, BitBucket, Gerrit — same hosting + collaboration |
| Founded | 2008 |
| Rank | World's largest host of source code |
| Early 2020 | 40 million+ users, 190 million+ repos |
| Free tier | Unlimited public **and** private repos, unlimited collaborators |
| Paid tiers | Team, Enterprise |

## Why bother

| Reason | Why |
| --- | --- |

## Remotes

<CodeBlock lang="bash" title="remote commands">{`# remote = destination: a label + the URL where a hosted repo lives

git remote                 # list names
git remote -v              # verbose: names + URLs (empty until you add one)

git remote add <name> <url>

git remote add origin https://github.com/blah/repo.git
# "whenever I say origin, I mean this GitHub URL"
# origin: convention, not keyword — clone's default, renameable, rarely renamed
git remote -v              # check your work — it shows up now

git remote add mygithuburl https://github.com/meh/repo.git
# any label works — just not a common choice

git remote rename <old> <new>   # rarely needed
git remote remove <name>        # rarely needed`}</CodeBlock>

<Callout type="warning">
Adding a remote talks to **nothing** — it only records a URL locally.
</Callout>

## In 30 seconds

| Command | Moves your code |
| --- | --- |
| `git add` | Workspace → Staging (index) |
| `git commit` | Staging → Local repo |
| `git push` | Local repo → Remote repo |
| `git fetch` | Remote repo → Local repo |
| `git pull` | Remote repo → Workspace |
