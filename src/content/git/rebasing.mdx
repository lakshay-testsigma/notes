<Analogy>
Merging staples master into your branch again and again. Rebasing picks your
branch up and re-plants it on master's tip.
</Analogy>

<TLDR>
- Two uses: **an alternative to merging**, and **a cleanup tool**.
- `git rebase master` moves your feature branch to **begin at master's tip**.
- All the work is still there, but history is **re-written** — brand-new commits.
- Payoff: **linear history, no unnecessary merge commits**.
- **Never rebase commits you have already shared.** Seriously.
</TLDR>

## The fix: rebase instead

<CodeBlock lang="bash" title="Rebase feature onto master">{`git switch feature   # stand on the branch you want to move
git rebase master    # re-plant it so it BEGINS at master's tip`}</CodeBlock>

| | Merge master in | Rebase onto master |
| --- | --- | --- |
| Result | Extra merge commit each time | No merge commit |
| Shape | Branchy, muddied | Linear |
| Commits | Originals kept | **New** commits re-created |
| History | Preserved | **Re-written** |

## Use 2 — rewriting history

<Steps
  linked={false}
  caption="Four cleanups, all before you share — git rebase -i does every one of them."
  items={[
    { icon: "✏️", label: "Rewrite", note: "Change what a commit contains." },
    { icon: "🗑️", label: "Delete", note: "Drop a commit entirely." },
    { icon: "🏷️", label: "Rename", note: "Edit the commit message." },
    { icon: "🔀", label: "Reorder", note: "Move commits up or down the list." }

/>

<CodeBlock lang="bash" title="Interactive rebase">{`# -i = interactive mode; HEAD~4 = how far back to rewrite
git rebase -i HEAD~4`}</CodeBlock>

<Callout type="info">
Note: here we are **not** rebasing onto another branch. We are rebasing a series
of commits onto the HEAD they are currently based on.
</Callout>

## What now?

<Steps
  caption="One interactive rebase, beat by beat."
  items={[
    { icon: "📝", label: "Editor opens", note: "A todo list of commits, each prefixed pick." },
    { icon: "🔤", label: "Swap verbs", note: "Replace pick with reword, edit, fixup or drop." },
    { icon: "💾", label: "Save and close", note: "Git replays the series as brand-new commits." }
  ]}
/>

| Command | Does |
| --- | --- |
| `pick` | Use the commit |
| `reword` | Use the commit, but edit the commit message |
| `edit` | Use the commit, but stop to amend — add files, fix content |
| `fixup` | Meld contents into the previous commit, discard its message |
| `drop` | Remove the commit |
| …more | The editor lists others too — `squash`, `break`, `exec` |

<CodeBlock lang="text" title="Before — the editor hands you this">{`pick f7f3f6d Change my name a bit
pick 310154e Update README
pick a5f4a0d Add cat-file`}</CodeBlock>

<CodeBlock lang="text" title="After — swap 'pick' for what you want">{`drop   f7f3f6d Change my name a bit
pick   310154e Update README
reword a5f4a0d Add cat-file`}</CodeBlock>
