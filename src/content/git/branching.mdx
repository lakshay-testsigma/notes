<TLDR>
- A **branch** = a separate context. Changes stay there **unless you merge**.
- You are **always on a branch\*** — default `master`, no special powers. *(\*except detached HEAD, later.)*
- **HEAD** = a pointer to where you are; it points at a branch reference.
</TLDR>

## The master branch

<CodeBlock lang="bash" title="you've seen this">{`On branch master
nothing to commit`}</CodeBlock>

| Belief | Reality |
| --- | --- |
| "master is special" | Just a branch. No fancy powers. |
| "master holds the master copy" | It doesn't have to. |
| "master is the official source of truth" | Your team's convention, not a Git rule. |

<Callout type="info">
In 2020 **GitHub** renamed its default branch `master` → `main`. Git's own default
is still `master`; the Git team is exploring a change.
</Callout>

## The commands

| Command | Does |
| --- | --- |
| `git branch` | List branches; `*` = the one you're on |
| `git branch -v` | Same, plus last commit + message |
| `git branch <name>` | Create at HEAD — **does not** switch |
| `git switch <name>` | Move HEAD onto that branch |
| `git switch -c <name>` | Create **and** switch (`-c` = create) |
| `git checkout <name>` | The old way to switch; still works |

<CodeBlock lang="bash" title="day-to-day">{`git switch -c refactor                        # new refactor branch, and you're on it
git config --global init.defaultBranch main   # the default branch is configurable`}</CodeBlock>

<CodeBlock lang="bash" title="git branch -v">{`* master      88df51f   add documentation
  bugfix      7c2a586   fix hover bug
  chatdemo    afadcf9   add chat widget`}</CodeBlock>

<Callout type="info">
`checkout` does a million additional things, so a simpler standalone `switch` was
added. Older tutorials use `checkout` — both work.
</Callout>
