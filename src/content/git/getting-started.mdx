<Analogy>
Git is a terminal tool wearing a GUI costume. The costume is optional — the tool underneath never changes.
</Analogy>

<TLDR>
- Git was built as a **command-line tool**: you type `git` commands into a Unix shell.
- **GUIs** are friendlier wrappers over the same thing.
- Developer, or becoming one? **Learn the command-line** — you'll need it anyway.
- Install: Mac → installer package. Windows → Git For Windows, which gives you **Git Bash**.
- Configure once: `user.name` and `user.email`. **No account, no signup.**
</TLDR>

## Git is (primarily) a terminal tool

Not the friendliest experience — but it is the very core of Git.

<CodeBlock lang="bash" title="the usual shape">{`git <command> [--flags] [args]   # e.g. git commit -m "message"
`}</CodeBlock>

## GUI vs command-line

### 🖱️ GUI clients

| ✅ Pros | ⚠️ Cons |
| --- | --- |
| Low barrier for beginners | Lots of "magic" |
| Friendlier — when it works | Inner workings hidden |
| Visual, even for CLI experts | Locked to one piece of software |
| | No CLI = hard to fix a mess |
| | Buttons vary between GUI's |

### ⌨️ Command-line

| ✅ Pros | ⚠️ Cons |
| --- | --- |
| All docs use it | Not beginner-friendly. At all |
| Way faster once comfortable | Commands hard to remember at first |
| Advanced features are CLI-only | Bad experience even for some pros |
| Same commands on every machine | |

<Callout type="info">
The CLI-vs-GUI thing is largely preference. There is a lot of stupid GUI gate-keeping out there — ignore it.
</Callout>

## Configuring Git

Two facts Git attaches to every commit.

<Steps
  linked={false}
  caption="Run once, before your first commit."
  items={[
    { icon: "🧑", label: "Your name", note: "Stamped on every commit." },
    { icon: "✉️", label: "Your email", note: "Match your GitHub account later." },
    { icon: "🖱️", label: "On a GUI", note: "Prompts you on first launch." }
  ]}
/>

<CodeBlock lang="bash" title="run once, globally">{`# --global = every repo for this user account
# the name Git will associate with your work
git config --global user.name "Tom Hulce"

# your email — match it to your Github account later
git config --global user.email blah@blah.com
`}</CodeBlock>
