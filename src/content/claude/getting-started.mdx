<TLDR>
- **One curl command** installs it; type **`claude`** to start; authorize in the browser **once**.
- Always run it **inside your project folder** — it reads and understands your codebase.
- **Bash Mode** (`Shift + !`) runs shell commands in the chat; **Ollama** is the free alternative.
</TLDR>

## Running the Flask project

<CodeBlock lang="bash" title="venv, install, run">{`python3 -m venv venv             # 1. create a virtual environment
source venv/bin/activate         # 2. activate it (Windows: venv\\Scripts\\activate)
pip install -r requirements.txt  # 3. install dependencies
python3 app.py                   # 4. run — server starts at http://localhost:5001`}</CodeBlock>

| Layer | Technology | Purpose |
| --- | --- | --- |
| Backend | Python 3.11 + Flask | Server-side logic, routing |
| Database | SQLite | Lightweight file-based database |
| ORM | Flask-SQLAlchemy | Python interface to SQLite |
| Templating | Jinja2 | Generates dynamic HTML pages |
| Frontend CSS | Vanilla CSS | Styling |
| Fonts | Google Fonts | Custom typography |
| Testing | pytest + pytest-flask | Automated testing |

## Bash Mode

Press **`Shift + !`** in the chat to switch modes. Claude **remembers** the
commands you run, **sees** their output, and answers questions about them later.

<Diagram caption="One keystroke toggles modes — and the output feeds the conversation." chart={`

  C["chat mode"] -- "Shift + !" --> B["bash mode"]
  B --> S["shell runs it"]
  S --> O["output joins chat"]
`} />

Bash Mode:  you type commands -> they execute in the shell

## Free alternatives — Ollama

<CodeBlock lang="bash" title="method 1 — cloud models (free tier)">{`curl -fsSL https://ollama.ai/install.sh | bash   # install Ollama
ollama launch claude                              # launch Claude Code with it`}</CodeBlock>

<CodeBlock lang="bash" title="method 2 — local models (fully free)">{`ollama pull qwen2.5-coder:7b   # download a model
ollama launch claude           # then select your local model from the list`}</CodeBlock>

## Quick reference

| Command | Does |
| --- | --- |
| `curl … \| bash` | Install Claude Code |
| `claude` | Start Claude Code (paid) |
| `claude --help` | Show help and options |
| `Shift + !` | Toggle Bash Mode |
| `/exit` | End the current session |

## In 30 seconds

- **Install** with one curl command; **run `claude` inside your project folder** — always.
- Authorize in the browser **once**; ask **overview questions first**, before writing code.
- **Bash Mode** (`Shift + !`) for shell commands; **Git from the start** — you'll deploy later.
