## Hook exit codes

Your hook script's exit code is its answer to "may this tool run?"

| Code | Meaning | Effect |
| --- | --- | --- |
| `0` | OK | Tool executes normally |
| `1` | Warning | Tool still executes, error logged |
| `2` | Block | Tool is cancelled |

<Diagram caption="Only exit code 2 stops the tool — 0 and 1 both let it run." chart={`
flowchart LR
  H[hook exits] --> Z["0"] --> R[runs]
  H --> O["1"] --> L[runs + log]
  H --> T["2"] --> X[cancelled]
`} />

## In 30 seconds

- **Session**: `claude` → `/rename` → `/exit` → `claude -r`.
- **Context**: `/context` to check, `/btw` for asides, `/compact` before `/clear`.
- **Git**: branch off main → commit → push → PR → cleanup.
- **Hooks**: exit `2` blocks the tool; `0` and `1` let it run.
- **MCP**: local tool → `stdio`, remote API → `http`.
