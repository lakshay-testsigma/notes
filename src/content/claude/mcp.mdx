## What is MCP?

A standardized way to plug any external tool, service, or data source into an LLM — no brittle custom code.

| Property | Detail |
| --- | --- |
| Full form | Model Context Protocol |
| Created by | Anthropic |
| Type | Open standard / universal connector |
| Purpose | Connect any external tool/service to any LLM |
| Adoption | Virtually every major AI player today |

## Why MCP in Claude Code?

Claude Code alone is limited to your local file system and shell. MCP breaks those limits.

| Default tool | What it does |
| --- | --- |
| `Read` | Read files from the file system |
| `Write` | Create new files / write into existing ones |
| `Bash` | Execute command-line / shell commands |

<Callout type="info">
With MCP, add: **GitHub** repos/issues/PRs, **Google Drive** docs, **Jira** tickets,
**Slack** messages, **Figma** designs, **databases** (SQLite, MySQL, PostgreSQL), AWS, Docker, Notion — and more.
</Callout>

## Integration 1 — SQLite database

One server, three databases: `@executeautomation/database-server` speaks SQLite, MySQL and PostgreSQL.

<CodeBlock lang="bash" title="add the database server (local → stdio)">{`claude mcp add --transport stdio sqlite -- \\
  npx -y @executeautomation/database-server \\
  /absolute/path/to/spendly.db`}</CodeBlock>

| Transport | Use case |
| --- | --- |
| `stdio` | Local — process runs on your machine |
| `http` / `sse` | Remote — server runs on a remote host |

<CodeBlock lang="bash" title="verify, then just ask">{`/mcp    # SQLite server should show: Connected

# example prompts — zero Python, zero SQL:
List all tables in the Spendly database
Describe the schema of the expenses table
Show total spending grouped by category`}</CodeBlock>

## Integration 3 — GitHub

Read repos, issues, PRs; create/merge PRs; push commits — the entire Git workflow, automated.

<Steps
  caption="Step 1 — create a fine-grained Personal Access Token."
  items={[
    { icon: "⚙️", label: "Navigate", note: "github.com → Settings → Developer Settings → Personal Access Tokens → Fine-grained." },
    { icon: "🆕", label: "Generate", note: "Click Generate new token; set name, expiry, repo access." },
    { icon: "🔑", label: "Permissions", note: "repo (read/write repos, PRs, issues) + workflow (Actions) + PR create/merge." },
    { icon: "📋", label: "Copy now", note: "Copy the token immediately — it's shown once." }
  ]}
/>

<Callout type="warning">
Always enable **PR create + merge permissions explicitly** — forgetting this causes failures at merge time.
</Callout>

<CodeBlock lang="bash" title="step 2 — add the server (remote → http)">{`export PAT=github_pat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

claude mcp add --transport http github \\
  https://api.githubcopilot.com/mcp \\
  -H "Authorization: Bearer $PAT"`}</CodeBlock>

| Prompt | What happens |
| --- | --- |
| "Which is my most starred repo?" | Lists top-starred repo with stars/forks |
| "How many open issues? Summarize" | Groups all issues by category |
| "Are there open PRs? Summarize them" | Lists PRs with summaries |
| Full git workflow automation | Commit, push, PR, merge, cleanup in one shot |

<CodeBlock lang="text" title="the full-automation prompt">{`Commit all changes with an appropriate conventional commit message,
push to the current feature branch, create a pull request into main
with a proper title and description based on the spec, merge it
using squash merge, switch to main, pull latest, and delete the
feature branch locally.`}</CodeBlock>

## Managing servers

<CodeBlock lang="bash" title="add · list · reconnect · remove">{`# local (stdio)
claude mcp add --transport stdio <name> -- <command> <args>
# remote (http)
claude mcp add --transport http <name> <url> -H "Authorization: Bearer $TOKEN"

/mcp                            # list all servers / reconnect (inside Claude Code)
claude mcp remove <server-name>`}</CodeBlock>

<Callout type="warning">
**Don't overload MCP servers** — the single biggest beginner mistake. Every tool's
description auto-loads into Claude's context at the start of **every** session:
wasted tokens, slower responses, degraded performance. Keep the list **minimal**;
remove what you don't genuinely use.
</Callout>

  B --> D["/mcp: Connected?"]

- Golden rules: **stdio local, http remote** · minimal permissions · verify with `/mcp` first.
- **Minimal server count**, absolute paths for local DBs, PAT needs PR create+merge.
- **Never** install every server you find; **never** commit your PAT/API keys to Git.
