<TLDR>
- **Slash commands** = shortcuts starting with `/` that trigger a predefined action instantly.
- A **session** = one conversation, from running `claude` to typing `/exit` — auto-saved, resumable.
- Discipline: **one session = one task**, `/rename` it immediately, watch `/usage`.
</TLDR>

## The problem they solve

Programmers repeat the same requests — closing sessions, switching models, checking usage. A full prompt each time is waste.

## Two types

| Type | What it is |
| --- | --- |
| **Built-in** | Pre-installed with Claude Code — `/exit`, `/model`, `/resume`, `/config` |
| **Custom** | Commands **you** create for your own workflow |

## Session best practices

| Practice | Why |
| --- | --- |
| One session = one task | Separate session per feature |
| Name it immediately | `/rename` right away |
| Commit frequently | Git commit at every milestone |
| `/btw` for quick questions | Keeps the main conversation context clean |
| `/export` before big refactors | Save context as a file first |

## /exit /resume /rename — session trio

<CodeBlock lang="bash" title="open, switch, label">{`/exit                    # close session, back to the normal terminal
/resume                  # list all past sessions, pick one, Enter
/rename intro-session    # proper names = easy to identify later`}</CodeBlock>

## /btw — side questions without polluting context

"By The Way": quick reference questions that never enter your conversation history.

<CodeBlock lang="bash" title="ask on the side">{`/btw What is Jinja templating engine in Flask?`}</CodeBlock>

## /config — settings

| Setting | Default | Does |
| --- | --- | --- |
| Auto-compact | true | Compresses long conversations automatically |
| Thinking mode | true | Enables step-by-step reasoning |
| Terminal progress bar | true | Progress bar for long operations |
| Show turn duration | true | Shows how long each turn takes |
| Default permission mode | Default | Controls default tool permissions |
| Auto-update channel | latest | Which update channel to follow |

## /permissions — who touches what

Claude Code is an agent with tools (read, write, bash, web search) — by default it **asks** before using any of them.

| Tab | Meaning |
| --- | --- |
| Allow | Used **without asking** |
| Ask | **Always asks** before each use (default) |
| Deny | **Never** used |
| Workspace | Workspace-level permission settings |

| Scope | Applies to |
| --- | --- |
| Local project | Only you, only this project |
| Global project | Everyone (stored in `.claude/` folder) |
| User | All projects on your machine |

<Callout type="warning">
Be extremely careful with the **Allow** list — only tools that are safe to run without your review.
</Callout>

## Quick reference — all key commands

| Command | Purpose | Category |
| --- | --- | --- |
| `/exit` | Close the current session | Session |
| `/resume` | Switch to a different past session | Session |
| `/rename <name>` | Rename the current session | Session |
| `/btw <q>` | Side question without polluting context | Productivity |
| `/export <file>` | Export conversation to a file | Data |
| `/logout` · `/login` | Log out / log in | Account |
| `/model` | Switch Opus / Sonnet / Haiku | Model |
| `/usage` | Check current token usage | Monitoring |
| `/extra-usage` | Purchase additional tokens | Monitoring |
| `/stats` | View usage statistics | Analytics |
| `/insights` | Detailed usage analysis report | Analytics |
| `/config` | Modify Claude Code settings | Configuration |
| `/permissions` | Manage tool permission rules | Security |
| `/theme` | Change visual appearance | Personalization |
| `/voice` | Toggle voice input mode | Input |

## In 30 seconds

- One `/word` → full prompt → whole workflow. Start with `/exit`, `/model`, `/rename`, `/btw`, `/usage`.
- **Session discipline**: one session per task, rename immediately, commit frequently.
- **Model strategy**: Opus for planning → Sonnet for implementation.
- Check `/usage` regularly so limits never surprise you.
